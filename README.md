# 研岸 · 考研自习打卡

网页应用全部在 `www/` 目录（单文件 `www/index.html`，无外部依赖、可完全离线）。用 Chrome/Edge 双击 `www/index.html` 即可使用。

## 功能
- **今日**：考试倒计时、每日目标时长进度、任务完成率、待复习错题入口；番茄钟计时（专注/短休/长休，支持暂停、关页重开按真实时间续算）；任务清单（可提前计划、可事后补记，状态：完成/未完成/放弃）；练习正确率记录（科目 + 内容标签 + 做对/总题数）；手动补记时长；每日备注；支持切换到任意历史日期补录。
- **错题本**：数学、专业课等任意科目可录入错题（题干 + 答案解析 + 错因 + 可选照片，照片自动压缩）。采用多轮间隔复习：默认 1 / 3 / 7 / 14 / 30 天；答对进入下一轮，答错重置回第 1 轮，最后一轮答对标记“已掌握”。支持“今日复习”队列、提前复习、编辑、删除、查看历史对错。
- **统计**：近 7 / 30 天专注时长柱状图、科目时长占比、任务完成率趋势、每日正确率折线、按科目/内容标签的正确率、错题复习统计（各轮次正确率、按科目正确率等）。
- **设置**：科目管理（预置 政治/英语/数学/专业课，可增删改、自定义颜色）、番茄钟参数、复习间隔、每日目标、考试日期、浅色/深色/跟随系统主题、数据备份。

## 使用
1. 用 Chrome 或 Edge 打开 `www/index.html`（也可在浏览器中按 `Ctrl+O` 选择文件）。
2. 数据自动保存在当前浏览器的 localStorage 中，无需注册、无需联网。
3. 建议在“设置 → 数据备份”中**定期导出 JSON** 保存到网盘/U盘，防止换电脑或清浏览器缓存丢失数据。

## 数据与备份
- 数据格式：本地存储键 `kaoyan_daka_v1`；错题照片以压缩后的 dataURL 存于本地。
- 浏览器 localStorage 上限约 5MB（照片是大头）。接近上限时界面会提示；请及时导出备份，或删除不用的错题/照片。
- “导出备份 JSON”会包含全部数据（含照片，文件可能较大）；导入时会先自动备份并提示确认后全量替换。
- 更换浏览器/设备：在旧浏览器导出 → 新浏览器打开本页 → 导入即可。

## 小贴士
- 想快速验证番茄钟结算：把“专注（分钟）”临时改成 1，完成一个番茄后改回来即可。
- 当天没来得及打开电脑？第二天在“今日”左上角切到昨天，用“手动补记”补录时长、任务与练习。

## 说明
- 纯 `file://` 使用，无网络请求，代码全部在单个 `www/index.html` 内。
- 复习对错由你自己判定（先回忆，再显示答案，自评答对/答错）。
- 错题本对所有科目开放，默认预置科目中主要用于数学与专业课。
## 📱 安装到手机（App 方式）
本页面已内置 PWA 能力（`manifest.webmanifest` + 图标 + 离线缓存 `sw.js`），可以像 App 一样安装到手机上使用：

- **安卓（推荐，最接近“App”）**：把整个文件夹发布到任意 **HTTPS** 静态空间（GitHub Pages / Netlify / Vercel / Cloudflare Pages 等均可），然后用手机 Chrome 打开网址 → 菜单里选 **“安装应用”/“添加到主屏幕”**。之后会以独立窗口全屏运行、离线可用，桌面上有自己的图标。
- **iPhone（Safari）**：打开网址后点 **分享 → 添加到主屏幕**，可全屏使用（iOS 无独立安装包，这是官方方式）。
- 手机上的数据保存在手机浏览器本地，与电脑版互相独立；换设备/换浏览器用“设置 → 导出/导入 JSON”迁移。
- 需要**真正的安卓 .apk 安装包**时，需先在本机安装 JDK 17 + Android SDK（约 2GB），再用 Capacitor 把本文件夹打包成 APK（构建命令与步骤可再生成）；iOS 安装包则必须有 Mac + Xcode + Apple 开发者账号，Windows 上无法产出。
